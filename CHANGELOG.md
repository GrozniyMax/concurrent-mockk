# История изменений

## Unreleased — 0.2.0-SNAPSHOT

- Автоматическая интеграция с io.mockk.mockk, стандартными аннотациями и MockKExtension через ServiceLoader.
- Контекст до конструктора теста, scoped registry и отдельный кэш внедрения MockKExtension.
- Независимые Java static и Kotlin top-level mocks, адресные clear/unmock и восстановление оригинального метода.
- Регрессионные тесты параллельной работы, lifecycle, статической отмены и ошибок создания экземпляра.

## 0.1.0 — 2026-11-24

- Workflow GitHub Releases по стабильным тегам, релизные версии через Gradle property.
- Подготовка JitPack, инструкции подключения через Gradle и Maven.
- Релизные JAR, sources, POM, SHA-256 и проверка потребителя Maven-артефакта.
- Создание моков через `com.grozniy.mockk` без явной передачи контекста.
- Расширение JUnit 5 с отдельным контекстом каждого теста и адресной очисткой моков.
- Удаление привязки к потоку после теста и восстановление предыдущей при вложенном запуске.
- Тесты параллельного выполнения, lifecycle и обработки ошибок.
- Отдельный проект-пример, CI, MIT-лицензия, sources JAR и Maven-публикация для локальной проверки.
